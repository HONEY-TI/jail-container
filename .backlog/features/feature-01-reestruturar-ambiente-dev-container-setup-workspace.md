## Contexto / Problema

O ambiente de desenvolvimento precisava consolidar a configuração do container,
do Compose e do workspace, removendo arquivos legados e centralizando o setup.

## Objetivo

Atualizar o Dev Container para um fluxo de desenvolvimento mais consistente,
com configurações Docker e scripts de inicialização alinhados ao workspace.

## Critérios de aceite

Rascunho: revisar manualmente os critérios após validar a execução do ambiente.
